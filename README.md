# Esuda-2027
Aulas Curso de ADS - Analise e Desenvolvimento de Sistemas

Dashboard de análise de dados em Python para explorar arquivos sintéticos, como CSV e Excel, simulando um ambiente de análise de dados para testes, estudos e projetos de Inteligência Artificial.

A proposta é usar Streamlit, Pandas e Plotly para criar uma interface web simples, com indicadores, gráficos e visualização dos dados, sem precisar desenvolver HTML ou JavaScript.
